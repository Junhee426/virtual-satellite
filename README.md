# Virtual Satellite Lab v0.3

여러 소형위성의 신호를 하나의 가상 안테나처럼 합성하는 조건을 실험하는 브라우저 앱입니다.

## 실행
```bash
npm test
npm run build
npm start          # node scripts/serve.mjs → http://localhost:8000
```
브라우저에서 `http://localhost:8000`을 엽니다. 외부 API/CDN/서버 계산이 필요 없습니다. 초점 지도와 95% 보장 계산은 모듈 Worker에서 돌기 때문에 `file://`이 아닌 HTTP로 열어야 합니다(Worker를 쓸 수 없으면 메인 스레드에서 계산합니다). `render.yaml`으로 Render Static Site 배포가 가능합니다.

## V0.3 변경 사항

- **초점 지도 자동 범위**: 기본값이던 10 km 폭은 표본 간격(83 m)이 주빔(λR/B ≈ 16.5 m)과 격자 로브 간격(≈ 49.5 m)보다 넓어 모아레만 보였습니다. 이제 ‘빔 폭에 맞춤’이 기본이며, 주빔을 3표본 이상으로 나누고 이웃 격자 로브(λR/d)까지 보이도록 폭을 정합니다. 예측한 격자 로브 위치를 점선 원으로 표시합니다. v0.2 JSON 중 기본 폭(10 km)을 쓴 파일은 자동 범위로, 폭을 바꾼 파일은 직접 입력으로 불러옵니다.
- **95% 보장 요구 조건**: 평균 E[C] 곡선 옆에 하위 5% 결맞음 곡선과 95% 보장 경로·위상 RMS를 표시합니다(공통 난수 몬테카를로 1,000회 + 이분 탐색). 현재 시나리오의 위상 오차 예산(경로·RF·주파수·속도·위상 확산의 제곱합 제곱근)을 곡선 위에 찍고, 오차 실현값만 바꾼 몬테카를로 400회로 평균 손실과 95% 손실을 보여 줍니다.
- **시간 오차 모델 추가**: 속도 추정 오차(mm/s, 잔여 도플러 v/λ)와 발진기 위상 랜덤워크(°/√s, D·√t). 둘 다 0이면 기존 시나리오 결과는 v0.2와 비트 단위로 같습니다. 실제 궤도(SGP4)가 아니라 편대 상대운동 잔차만 다루는 단순화 모델입니다.
- **링크 공유**: 기본값과 다른 설정과 현재 탭을 URL 해시에 저장합니다(`#nodes=4&formation=Ring&tab=req`). ‘링크 복사’ 버튼을 제공합니다.
- **재현성**: 난수 시드를 입력하거나 새로 뽑을 수 있습니다. CSV에 모든 설정, 빔 폭·격자 로브, 몬테카를로 결과를 담습니다. JSON 스키마는 `virtual-satellite-v0.3`입니다.
- **색상**: 위상은 부호가 보이는 순환 색상표(0° 민트 · +90° 파랑 · ±180° 주황 · −90° 분홍), 초점 지도는 지각적으로 균일하고 색각이상에 안전한 cividis 근사를 씁니다.
- **접근성·조작성**: 탭은 WAI-ARIA Tabs 패턴(`role=tab`, `aria-selected`, 방향키·Home·End)을 따릅니다. 설정·요약·결과 패널은 한 번 만든 뒤 값만 갱신하므로 재생 중에도 버튼 클릭과 키보드 포커스가 유지됩니다.
- **코드**: `physics.js`·`state.js`·`app.js`를 읽을 수 있는 형태로 풀어 쓰고, 물리·상태 모듈에 `// @ts-check` JSDoc 타입을 붙였습니다. 모든 `?v=` 캐시 버전은 `package.json` 버전과 같아야 하며 `npm run build`가 이를 검사합니다.

## V0.2 시각화

- 핵심 지표: 신호 합성률, 결맞음 손실, 비결맞음 대비 이득을 함께 표시합니다.
- 편대 배치: 거리 눈금, 위성별 위상 색상, 클릭 및 Enter/Space 선택으로 위치·경로방향 오차·잔여 위상을 확인합니다.
- 빔·초점: 121×121 전력 지도, dB 색상 범례, 중앙 가로 단면, 범위 전환(빔 폭에 맞춤 ↔ 넓게 보기)을 제공합니다.
- 위상 동기: 위성별 위상과 평균 합성 벡터, 0–2초 재생·정지·시간 탐색을 제공합니다.
- 요구 조건: 위상 RMS에 따른 평균 결맞음 곡선과 주파수별 경로 정밀도를 비교합니다.
- 정상 정렬 / 3 mm 경로 오차 / 0.35 Hz 주파수 오차 예시를 바로 불러올 수 있습니다. 예시는 전체 설정을 교체합니다.
- 모바일에서는 ‘실험 설정 ↓’와 ‘결과로 ↑’로 설정과 결과를 오갑니다.
- 기존 JSON 시나리오를 계속 지원합니다. 숫자 범위를 제한하고 잘못된 타입·선택지는 기본값으로 대체합니다.
- 숫자 입력은 입력 중 유효한 값을 즉시 계산에 반영하되 입력란은 그대로 두므로 `0.005`처럼 0이 이어지는 소수도 입력할 수 있습니다. 빈 값이나 숫자가 아닌 값으로 입력을 마치면 직전 값으로 되돌립니다.
- 초점 지도는 위성별 보정 위상을 한 번만 계산해 64대·121×121 지도 계산 시간을 약 절반 이하로 줄였습니다. 결과는 기존 계산식과 비트 단위로 같습니다.

지도와 단면의 0 dB는 현재 지도에서 표본화된 최대 전력입니다. 넓은 지도에서는 좁은 피크를 놓칠 수 있으므로 중앙 빔 확대와 상단 목표점 수치를 함께 확인하세요. 위상 벡터 길이의 제곱이 결맞음 계수입니다. 높은 주파수 오차는 재생 화면의 갱신 속도보다 빠르게 변할 수 있습니다.

배치도의 경로 추정 오차는 모델의 z 방향에만 적용되므로 x/y 평면에서 실제 위치와 겹칩니다. 위성 선택 정보에서 Δz를 확인할 수 있습니다. 배열 크기 B는 생성 기준 길이이며 격자 대각선 최대 거리는 B보다 큽니다.

## 검증

| 명령 | 내용 | 필요한 설치 |
|---|---|---|
| `npm run build` | 단위 테스트 18개(물리·시나리오·그래프 수치 일치·몬테카를로 통계·링크 공유) + 배포 파일·구문·캐시 버전 검사. Render가 실행합니다. | 없음 |
| `npm run typecheck` | `physics.js`·`state.js` JSDoc 타입 검사 | `npm ci` |
| `npm run test:e2e` | Playwright: 탭 키보드 조작, Worker 초점 지도, 재생 중 클릭, 위성 선택 포커스, 링크 공유, 요구 조건 화면, 모바일 가로 넘침 | `npm ci`, `npx playwright install chromium` |

GitHub Actions(`.github/workflows/ci.yml`)가 PR과 main 푸시마다 세 가지를 모두 실행합니다.

## 기존 기능
- 1~64개 노드: Grid / Ring / Line / Random
- 2/20/30 GHz 및 임의 주파수
- 구면파 거리, 실제 위치와 추정 위치 분리
- 총 RF 전력 고정 / 노드당 전력 고정
- Estimated / Oracle / None 위상 보정
- 경로 추정오차, 독립 RF 위상오차, 주파수 편차
- 결맞음 손실, 비결맞음 기준 대비 이득
- 2D 초점 지도, 1D 절단면, 복소 위상 벡터
- 평균 결맞음 손실 목표에서 허용 위상·경로 RMS 역산
- JSON 저장/복원, CSV 결과 저장

## 주의
협대역 단일 반송파의 순간 분산배열 실험입니다. 실제 5G/6G 용량·BER, 편대유지 성능, 실제 RF 하드웨어 성능을 뜻하지 않습니다. `path error RMS`는 보정 후 남는 등가 전파경로 오차이며 3차원 위치유지 오차와 동일하지 않습니다.
