# Virtual Satellite Lab v0.2

여러 소형위성의 신호를 하나의 가상 안테나처럼 합성하는 조건을 실험하는 브라우저 앱입니다.

## 실행
```bash
npm test
npm run build
python3 -m http.server 8000 --directory dist
```
브라우저에서 `http://localhost:8000`을 엽니다. 외부 API/CDN/서버 계산이 필요 없습니다. `render.yaml`으로 Render Static Site 배포가 가능합니다.

## V0.2 시각화

- 핵심 지표: 신호 합성률, 결맞음 손실, 비결맞음 대비 이득을 함께 표시합니다.
- 편대 배치: 거리 눈금, 위성별 위상 색상, 클릭 및 Enter/Space 선택으로 위치·경로방향 오차·잔여 위상을 확인합니다.
- 빔·초점: 121×121 전력 지도, dB 색상 범례, 중앙 가로 단면, 중앙 빔 확대를 제공합니다.
- 위상 동기: 위성별 위상과 평균 합성 벡터, 0–2초 재생·정지·시간 탐색을 제공합니다.
- 요구 조건: 위상 RMS에 따른 평균 결맞음 곡선과 주파수별 경로 정밀도를 비교합니다.
- 정상 정렬 / 3 mm 경로 오차 / 0.35 Hz 주파수 오차 예시를 바로 불러올 수 있습니다. 예시는 전체 설정을 교체합니다.
- 모바일에서는 ‘실험 설정 ↓’와 ‘결과로 ↑’로 설정과 결과를 오갑니다.
- 기존 JSON 시나리오를 계속 지원합니다. 숫자 범위를 제한하고 잘못된 타입·선택지는 기본값으로 대체합니다.

지도와 단면의 0 dB는 현재 지도에서 표본화된 최대 전력입니다. 넓은 지도에서는 좁은 피크를 놓칠 수 있으므로 중앙 빔 확대와 상단 목표점 수치를 함께 확인하세요. 위상 벡터 길이의 제곱이 결맞음 계수입니다. 높은 주파수 오차는 재생 화면의 갱신 속도보다 빠르게 변할 수 있습니다.

배치도의 경로 추정 오차는 모델의 z 방향에만 적용되므로 x/y 평면에서 실제 위치와 겹칩니다. 위성 선택 정보에서 Δz를 확인할 수 있습니다. 배열 크기 B는 생성 기준 길이이며 격자 대각선 최대 거리는 B보다 큽니다.

## 검증

`npm run build`는 물리 계산·시나리오 입력·그래프 수치 일치 테스트 10개와 배포 파일·JavaScript 구문 검사를 수행합니다. 브라우저에서 네 가지 보기, 위성 선택, 1/64대 입력, 원형 배치, 시간 재생, 초점 확대와 모바일 가로 넘침을 확인했습니다.

## 기존 기능
- 1~64개 노드: Grid / Ring / Line / Random
- 2/20/30 GHz 및 임의 주파수
- 구면파 거리, 실제 위치와 추정 위치 분리
- 총 RF 전력 고정 / 노드당 전력 고정
- Estimated / Oracle / None 위상 보정
- 경로 추정오차, 독립 RF 위상오차, 주파수 편차
- 결맞음 손실, 비결맞음 기준 대비 이득
- 2D 초점 지도, 1D 절단면, 복소 위상 벡터
- 평균 결맞음 손실 목표에서 허용 위상·경로 RMS 역산
- JSON 저장/복원, CSV 결과 저장

## 주의
협대역 단일 반송파의 순간 분산배열 실험입니다. 실제 5G/6G 용량·BER, 편대유지 성능, 실제 RF 하드웨어 성능을 뜻하지 않습니다. `path error RMS`는 보정 후 남는 등가 전파경로 오차이며 3차원 위치유지 오차와 동일하지 않습니다.
